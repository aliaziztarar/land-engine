# profile

Your own details: name, company, contact details, letterhead, logo, the folders you use, and your programme's rules. The setup skill fills this folder the first time you use the engine ("set me up"). Everything here is private: it is never copied when the engine is shared (`tools/make_public_copy.py` leaves it out).

- `profile.json`: details the scripts use (name, role, company, phone, email, reference prefix, folders, letterhead files).
- `profile.md`: your business model, deal rules and programme rules in plain words, read by every session.
- `letterhead.docx`, `site-map-a4.docx`: your letter and site map templates.
- `private-terms.txt`: words that must never appear in a shared copy (your name, phone, site names). The setup skill starts it; the engine adds to it as you work.
